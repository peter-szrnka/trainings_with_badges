# AWS trainings (FREE only!)

## AWS Educate / Emering Talent Community

Link: www.awseducate.com

**AWS Educate** offers free, beginner-friendly online trainings designed to introduce learners to cloud computing and Amazon Web Services (AWS). These courses cover foundational topics such as cloud concepts, AWS services, and basic technical skills for roles like cloud practitioner or developer. Each training includes short lessons, hands-on labs, and quizzes to reinforce learning. Assessments typically feature multiple-choice questions testing understanding of key AWS concepts and best practices, and a passing score unlocks a digital badge or certificate of completion.

Link: [explore.skillbuilder.aws](explore.skillbuilder.aws)

It offers a wide range of free and paid courses covering AWS fundamentals, technical skills, and role-based learning paths. The platform includes interactive labs, videos, and knowledge checks to reinforce learning. Users can also take official practice exams and earn digital badges or certificates upon completing certain courses or learning plans.

## Cloud Quest

Link:https://aws.amazon.com/training/digital/aws-cloud-quest/

**AWS Cloud Quest** is an interactive, game-based learning experience that helps users build practical cloud skills through virtual, scenario-driven challenges. Players complete real AWS tasks—such as deploying servers, managing databases, or securing environments—inside a simulated city. Each quest focuses on a specific role (e.g., Cloud Practitioner, Solutions Architect, Machine Learning Specialist). Progress is tracked through missions, quizzes, and hands-on labs, with successful completion earning digital badges that showcase practical AWS expertise.
